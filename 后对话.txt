0. 一句话定义

    Superpose 是一个“叠加态 agent”生态：卡片是 agent 的身份、记忆、密钥与运行时；Mesh 是 agent 活动、协作、训练、交易的世界；模型与算力全部外包。插入即坍缩，拔走即叠加。

它不是 Agent 框架，不是 AI 硬件，不是去中心化 SaaS。
它是 agent 主权基础设施 + 数字生命资产市场 + 复杂系统实验平台。

6.3 一致快照与分叉
text

任一 carrier 发起 snapshot：
1. 记录本节点状态 + 逻辑时钟
2. 广播 marker 给邻接 carrier
3. 在途消息计入快照
4. 所有 carrier 回报 → 全局一致快照
5. 从快照可并发分叉 N 条探索分支

这就是“分布式重置”：不是倒带，是从任意一致点分叉。

   ├─ 拿结构化 action
   ├─ 在目标节点上执行
   └─ 结果写回卡片上下文

7. 拔出
   节点权限回收，卡片带走全部上下文和记忆
   节点不留痕迹

text

1. 真实节点照常跑业务

五、核心概念
5.1 环境无关的光速运行叠加态
text

环境无关：
  Agent 不绑定任何特定环境。
  在哪个环境被实例化，就拥有那个环境的完整能力。
  换一个环境，能力随之切换，身份和记忆不变。

光速运行：
  插入即坍缩，拔走即叠加。
  没有启动延迟，没有迁移成本，没有“部署”这个动作。

叠加态：
  Agent 同时“在”所有接入的节点上。
  不插入时，它是叠加的；
  插入某节点，它在该节点坍缩为可用；
  拔走，回到叠加。

5.2 拔插鉴权
text

插入 = 鉴权
  物理接触是身份验证的第一因子
  SE 片内签名是第二因子
  生物识别是第三因子（可选）

拔出 = 权限回收
  该节点上该 agent 的一切权限立即失效
  不留残留、不留缓存、不留后门

没有密码、没有 API key、没有 session token
只有物理拔插 + 片内签名

5.3 数据分区、加密、权限分配
text

数据分区：
  P0 公开 / P1 内部 / P2 私密 / P3 机密 / P4 禁止导出
  按敏感度分区，按解锁条件分级

加密：
  存储加密（芯片绑定）
  传输加密（端到端）
  密钥永不出 SE

系统权限分配：
  Agent 在某节点上能做什么，
  由 Card 的 delegation + 节点的 policy 共同决定
  不是“管理员给你权限”，
  是“你带的身份和你插入的节点协商权限”

十、一句话闭环

    模型托管在供应商，Harness、上下文、机密信息、通用工具装在 PocketAgent 卡片里。

    Superpose 是登录时激活的组网协调层兼训练平台：读节点环境，经 Jev 类决策计算，汇聚全球组网的所有环境和权限信息，投影成 LLM 可消费的上下文；同一套架构在真实环境上做二次训练，跨系统任务真完成即 reward。

    插入即登录，拔出即离开。卡片带走一切，节点不留痕迹。

    Agent 以环境无关的叠加态在任意节点运行，获得事实上的主体性，是真正具有数字身份的对象。

    官方只做 OS、参考实现、和 Superpose Bench。不办联赛，不做市场，不搞文创。
